# Excel Data Entry Sample Dataset

This repository contains a sample Excel dataset created to demonstrate data entry, copy-paste work, data cleaning, and structured formatting using Microsoft Excel. The dataset is intended for portfolio and demonstration purposes.

## Dataset Overview
- **Dataset Name:** Company Information Dataset
- **Total Records:** 100
- **File Format:** Microsoft Excel (.xlsx)
- **Industry Focus:** Mobile / Casual Gaming
- **Data Source:** Publicly available information

## Dataset Contents
The dataset includes the following fields:
- Company Name
- Contact Person
- Phone Number
- Email ID
- Sector
- Location
- Company Website
- Google Play Store Link

## Work Demonstrated
- Accurate Excel data entry
- Copy-paste data collection
- Data cleaning and formatting
- Separation of unstructured data into structured columns
- Consistent and readable spreadsheet layout

## Tools Used
- Microsoft Excel
- Excel formulas for data cleaning and column separation

## Use Cases
- Data entry and record keeping
- Company or business listings
- Research and reference datasets
- Spreadsheet preparation for further analysis

## Disclaimer
All company details, contact information, and links included in this dataset are collected from publicly available sources and are used strictly for demonstration and portfolio purposes only. This dataset does not represent client work.
